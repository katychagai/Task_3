## Задание 3: UI-тесты на Selenium

### Автотесты для проверки UI Stellar Burgers в Google Chrome и Mozilla Firefox

### Реализованные сценарии

Созданы UI-тесты на Selenium, покрывающие следующие функциональности:

1. **Основной функционал** (`test_main_functionality.py`)
   - Переход по клику на «Конструктор»
   - Переход по клику на «Лента заказов»
   - При клике на ингредиент появляется всплывающее окно с деталями
   - Всплывающее окно закрывается кликом по крестику
   - При добавлении ингредиента в заказ увеличивается счетчик данного ингредиента
   - Залогиненный пользователь может оформить заказ

2. **Восстановление пароля** (`test_forgot_password.py`)
   - Переход на страницу восстановления пароля по кнопке «Восстановить пароль»
   - Ввод почты и клик по кнопке «Восстановить»
   - Клик по кнопке показать/скрыть пароль делает поле активным — подсвечивает его

3. **Личный кабинет** (`test_profile.py`)
   - Переход по клику на «Личный кабинет»
   - Переход в раздел «История заказов»
   - Выход из аккаунта

4. **Лента заказов** (`test_orders_feed.py`)
   - При клике на заказ открывается всплывающее окно с деталями
   - Заказы пользователя из раздела «История заказов» отображаются на странице «Лента заказов»
   - При создании нового заказа счётчик «Выполнено за всё время» увеличивается
   - При создании нового заказа счётчик «Выполнено за сегодня» увеличивается
   - После оформления заказа его номер появляется в разделе «В работе»

**Все тесты автоматически запускаются в Google Chrome и Mozilla Firefox**

### Структура проекта

- `tests/` - пакет, содержащий тесты, разделенные по функциональности:
  - `test_main_functionality.py` - тесты основного функционала
  - `test_forgot_password.py` - тесты восстановления пароля
  - `test_profile.py` - тесты профиля пользователя
  - `test_orders_feed.py` - тесты ленты заказов
- `src/pages/` - Page Object классы:
  - `base_page.py` - базовый класс для всех страниц
  - `main_page.py` - страница главной страницы
  - `login_page.py` - страница входа
  - `profile_page.py` - страница профиля
  - `orders_feed_page.py` - страница ленты заказов
  - `forgot_password_page.py` - страница восстановления пароля
  - `reset_password_page.py` - страница сброса пароля
- `src/locators.py` - централизованное хранение всех локаторов
- `src/urls.py` - централизованное хранение всех URL-адресов (API endpoints и UI страницы)
- `src/api_client.py` - клиент для работы с API (регистрация и удаление пользователей)
- `src/helpers.py` - вспомогательные функции для генерации данных
- `src/config.py` - конфигурация проекта (базовый URL)
- `src/browser_factory.py` - фабрика для создания WebDriver экземпляров
- `conftest.py` - фикстуры pytest для настройки драйверов Chrome и Firefox и аутентификации пользователей

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск всех тестов (автоматически в Chrome и Firefox)**

> `$ pytest tests/ -v`

**Запуск тестов только в Chrome**

> `$ pytest tests/ -v -k "chrome"`

**Запуск тестов только в Firefox**

> `$ pytest tests/ -v -k "firefox"`

**Запуск конкретного теста**

> `$ pytest tests/test_profile.py::TestProfile::test_go_to_personal_account -v`

**Запуск тестов с генерацией Allure отчетов**

> `$ pytest tests/ -v --alluredir=allure_results`

**Просмотр Allure отчетов**

> `$ allure serve allure_results`

### Особенности реализации

- **Page Object Pattern** - использование паттерна Page Object для организации кода
- **Параметризация браузеров** - автоматический запуск тестов в Chrome и Firefox через pytest параметризацию
- **Централизация локаторов** - все локаторы вынесены в отдельный файл `locators.py`
- **Централизация URL** - все URL-адреса вынесены в отдельный файл `urls.py`
- **Системные драйверы** - использование системно установленных драйверов браузеров
- **Явные ожидания** - использование WebDriverWait для стабильности тестов
- **Allure отчеты** - подробное логирование шагов тестов
- **Генерация данных** - использование Faker для создания тестовых данных
- **API интеграция** - использование API для создания и удаления тестовых пользователей
- **Изоляция тестов** - каждый тест создает и удаляет своего пользователя через API

### Требования

- Python 3.10+
- Google Chrome с установленным chromedriver 
- Mozilla Firefox с установленным geckodriver 
- Установленные зависимости из `requirements.txt`
